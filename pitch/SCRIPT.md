## Recording & putting it together

1. Record in a quiet room, mic ~15 cm away; one take per minute is easiest to fix later.
2. Play the video while reading — the **[0:00]** marks are your cues.
3. Put the voice on the video:
   ```bash
   cd pitch
   npm run mix -- "C:/path/to/voice.m4a"
   ```
   → `out/petnft-pitch-final.mp4` (video untouched, voice loudness-normalised; the video always plays to the end).
4. Change on-screen text, timings or the team in `config.json`, then `npm run build`.
5. If you have *any* user feedback (friends who played, a poll), add one sentence to minute 3 — judges value validation.
